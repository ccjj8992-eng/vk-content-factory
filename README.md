# VK Content Factory

Автоматическая публикация контента в VK.

## Возможности v1.0

- очередь публикаций;
- публикация по расписанию;
- VK API;
- журнал публикаций;
- журнал ошибок;
- FastAPI;
- Docker;
- Timeweb Cloud App Platform.

## Environment variables

VK_TOKEN=your_vk_token
VK_GROUP_ID=241102912
